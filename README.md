### About

I design and ship AI systems that do real work — not demos. My focus is the layer between a raw LLM call and a production automation: agent orchestration, tool use, deterministic testing for non-deterministic systems, and the developer tooling that makes all of that maintainable.

- 🤖 **AI Agents** — multi-agent pipelines for research, outreach, analysis, and data processing, built on the Claude API
- 🛠️ **Developer Tools** — MCP servers, workflow-testing frameworks, and CLIs that make AI-powered systems verifiable
- 🔗 **Automation** — CRM/ops workflows wiring together Close, HubSpot, Airtable, Notion, and n8n
- 📚 **Data Pipelines** — RAG pipelines, web scraping, and lead-enrichment systems
- 🔭 **Currently exploring** — deterministic evaluation and test coverage for agentic and n8n workflows
